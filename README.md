Diabetes Prediction using Machine Learning

Project Overview

This project predicts whether a person has diabetes using machine learning classification techniques.

Dataset

The project uses the Pima Indians Diabetes dataset.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Imbalanced-learn

Project Workflow

1. Data loading
2. Data preprocessing
3. Missing value handling
4. Exploratory Data Analysis (EDA)
5. Correlation analysis
6. Train-test splitting
7. Feature scaling
8. Handling class imbalance using SMOTE
9. Logistic Regression model training
10. Model evaluation

Model Performance

The Logistic Regression model achieved approximately 71% accuracy on the test dataset.

Conclusion

This project helped me understand the basic machine learning workflow, data preprocessing, classification, and model evaluation.
